# BlackICE

A dark, red-team-themed [Hexo](https://hexo.io) theme built for [r3vpwnx](https://github.com/r3vpwnx).

## Features

- Dark-only design, no light mode
- Fixed background image with a click-triggered "red team words" pop effect
- Top nav: Search, Home, Writeups, Articles, Archive, Tags, Categories, Cheatsheets, About
- Sidebar profile card with social links (GitHub, X, LinkedIn, Instagram)
- Client-side search (no backend required, works on GitHub Pages)
- All posts are plain markdown

## Configuration

See `_config.yml` in this theme folder for profile info, social links, background image path, the click-effect word bank, and nav links.
